# Space Local

2087: Mumbai's last local train, launched into orbit. A pixel-art endless runner: switch lanes to dodge broken signals,
outrun the ZORG, grab chai shields, halt at stations, and upgrade from the Mumbai Local to faster trains.
World leaderboard included.

**Play:** https://blogs.tanmaybohra.com/games/space-local.html

Built by [Tanmay Bohra](https://tanmaybohra.com). One self-contained HTML file: canvas rendering, sprites drawn in code,
synthesised audio, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8080      # then open http://localhost:8080
```

The world leaderboard talks to `api.tanmaybohra.com`.

## Controls

Up / down (or swipe) to change lanes, H for the horn, P to pause, M for sound.
